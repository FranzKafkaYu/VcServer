# 厂商绑定

[English](vendor-binding.en.md)

把已保存的 SSH 服务器绑定到一家厂商后，可在没有 SSH 连接时通过厂商 API 做电源等操作。凭据保存在**该服务器的绑定**上，仅存储在本地。

## 前提与入口

1. 先在列表中添加并保存 SSH 服务器。
2. 退出多选模式（多选时没有绑定入口）。
3. 打开该服务器的 **更多** 菜单，选择 **绑定厂商**。
4. 选择商家，按下方对应小节填写。厂商接受凭据并（如需）选出实例后才会保存绑定。

## 限制

- 一台服务器同时只能绑定 **一家** 厂商。要换商家，先解除当前绑定。
- 解除绑定只去掉该台的厂商关联，SSH 主机、端口和登录凭据仍保留。
- 厂商拒绝或网络失败时，不会保存绑定。

绑定成功后，同一 **更多** 菜单会出现开机、关机、重启、查看状态和解除绑定（部分商家还有服务器信息等，以应用内菜单为准）。

## 独立厂商 API

这类商家用各自自研的面板API。选择商家后填写该商家的密钥凭据，通过后再选择对应的服务器。

### BandwagonHost

应用内选项名为 **BandwagonHost**（俗称搬瓦工，文档与菜单均不使用「搬瓦工」或 HOST 作为选项名）。

填写：

- **VEID**
- **API key**

在 KiwiVM控制台取得上述字段。进入KiwiVM控制台后，找到`KiwiVM Extras->API`,即可获取VEID与API Key信息。  
同一 VEID 不能再绑到另一台 SSH 服务器。校验通过后即绑定到当前服务器。

### CloudCone

填写：

- **API Key**
- **API Hash**  

登录Cloudcone账号，点击右上角头像处，找到`API Settings->Generate new`,就会生成对应的`API Key`与`API Hash`,填入以上信息即可。需要说明的是，当前Cloudcone仅支持SC2类型的服务器通过API进行管理。      

厂商接受后，从该账号尚未绑定的实例中选择一台。

### GreenCloud

应用内选项名为 **GreenCloud**。

填写：

- **API Token**（客户区 API）    

登录Greencloud账号，进入服务器控制面板。点击`右上角账号->Account->API->Genetate Token`生成即可。  

厂商接受后，选择对应服务器的实例即可完成绑定。

## 通用面板类

这类商家走 Virtualizor/SolusVM 等面板 API。面板地址和密钥按 **当前服务器** 填写，不会自动填入其他服务器上已保存的密钥。

### Virtualizor

填写：

- **面板主机**
- **面板端口**
- **API Key**
- **API Pass**

证书不被系统信任时，应用会按 **该主机和端口** 询问是否信任指纹。凭据被面板接受后，选择尚未绑定到其他服务器的 VPS。
